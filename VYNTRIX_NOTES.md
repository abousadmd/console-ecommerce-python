# VYNTRIX — project notes

VYNTRIX is a smart-vending machine project being developed by Mouad Abousad. The intended system connects ESP32-based hardware to a web platform for device monitoring and inventory management.

## Project areas described during development

- ESP32 device connectivity and heartbeat/telemetry
- Product stock and machine status monitoring
- NFC membership identification and purchase authorization
- Backend APIs for device state and dispense results
- Web dashboard for inventory and machine health
